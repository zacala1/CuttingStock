# 테스트 케이스 설계서

## 1. 테스트 전략

### 1.1 테스트 목표
1. **정확성**: 모든 주문을 정확히 충족하는지 검증
2. **제약 준수**: 재고 수량, 용접 규칙 등 제약 조건 준수 검증
3. **성능**: 규모별 실행 시간 측정
4. **비용 최적화**: 알려진 최적해와 비교 (가능한 경우)

### 1.2 테스트 범위
- ✅ 단위 테스트: 개별 함수 동작 검증
- ✅ 통합 테스트: 전체 알고리즘 결과 검증
- ✅ 성능 테스트: 실행 시간 벤치마크
- ✅ 비교 테스트: 알고리즘 간 결과 비교

## 2. 테스트 케이스 목록

### 2.1 기본 케이스 (Basic Cases)

#### TC-001: 단순 완벽 매칭
**목적**: 자투리 없이 정확히 맞는 경우
```
재고: [10000mm × 1개]
주문: [5000mm × 2개]
기대 결과:
  - 절단: [5000, 5000]
  - 자투리: 0mm
  - 용접: 0회
  - 비용: 0원
```

#### TC-002: 자투리 발생 (재사용 가능)
**목적**: gamma 이상의 자투리 처리
```
재고: [10000mm × 1개]
주문: [4000mm × 2개]
파라미터: γ=1000
기대 결과:
  - 절단: [4000, 4000]
  - 자투리: 2000mm (재사용 가능)
  - 용접: 0회
  - 비용: 0원
```

#### TC-003: 자투리 발생 (폐기)
**목적**: gamma 미만의 자투리 처리
```
재고: [10000mm × 1개]
주문: [4500mm × 2개]
파라미터: α=1, γ=1500
기대 결과:
  - 절단: [4500, 4500]
  - 자투리: 1000mm (폐기)
  - 용접: 0회
  - 비용: 1000원
```

#### TC-004: 여러 재고 사용
**목적**: 복수 재고 처리
```
재고: [10000mm × 2개]
주문: [6000mm × 3개]
기대 결과:
  - 재고1: [6000, 4000 자투리]
  - 재고2: [6000, 4000 자투리] 또는 [6000, 3000 폐기]
  - 총 자투리 ≥ 4000mm
```

### 2.2 용접 케이스 (Welding Cases)

#### TC-005: 단순 용접
**목적**: 기본 용접 로직 검증
```
재고: [10000mm × 2개]
주문: [15000mm × 1개]
파라미터: β=500, δ=1000
기대 결과:
  - 재고1: [10000]
  - 재고2: [5000]
  - 용접: 1회 (10000 + 5000 = 15000)
  - 비용: 500원
```

#### TC-006: 용접 vs 자투리 트레이드오프
**목적**: 비용 최적화 검증
```
재고: [10000mm × 3개]
주문: [11000mm × 1개, 5000mm × 1개]
파라미터: α=1, β=500, δ=1000

옵션1 (용접 사용):
  - 재고1: [10000] → 11000 주문에 사용
  - 재고2: [1000] → 11000 주문에 사용 (용접)
  - 재고2: [4000 폐기]
  - 재고3: [5000, 5000 자투리]
  - 비용: 500 + 4000 = 4500원

옵션2 (용접 회피):
  - 재고1: [10000 폐기]
  - 재고2: [5000, 5000]
  - 재고3: [11000 불가능]
  - 실패

기대: 옵션1 선택
```

### 2.3 복잡한 케이스 (Complex Cases)

#### TC-007: 예제 데이터 (문서에서 사용)
**목적**: 실제 사용 사례
```
재고: [12000mm × 10개]
주문: [5000mm × 5, 3000mm × 8, 2000mm × 6]
파라미터: α=1, β=500, γ=1000, δ=1000

수동 계산:
  - 주문 총 길이: 5000×5 + 3000×8 + 2000×6 = 61000mm
  - 최소 재고 필요: ceil(61000/12000) = 6개

기대 결과:
  - 사용 재고: 6-8개
  - 총 비용: < 10000원
```

#### TC-008: 다양한 길이 조합
**목적**: 동적 계획법 검증
```
재고: [15000mm × 5개]
주문: [7000mm × 2, 4000mm × 3, 3000mm × 4, 2000mm × 5]
파라미터: α=1, β=500, γ=500, δ=500

검증 항목:
  - 모든 주문 충족
  - Knapsack 효율 (각 재고 활용률 > 80%)
```

### 2.4 경계 케이스 (Edge Cases)

#### TC-009: 빈 입력
```
재고: []
주문: []
기대: 빈 결과, 에러 없음
```

#### TC-010: 재고 부족
```
재고: [10000mm × 1개]
주문: [5000mm × 10개]
기대: 에러 또는 부분 충족 + 경고
```

#### TC-011: 주문 길이 > 재고 길이 (용접 불가)
```
재고: [10000mm × 10개]
주문: [20000mm × 1개]
파라미터: δ=15000 (용접 불가능하게 설정)
기대: 에러 또는 "불가능" 메시지
```

#### TC-012: 동일 길이 대량 주문
```
재고: [10000mm × 100개]
주문: [10000mm × 100개]
기대:
  - 완벽 매칭
  - 자투리: 0mm
  - 실행 시간: < 1초
```

### 2.5 성능 테스트 (Performance Tests)

#### TC-013: 소규모 (Small)
```
재고: 5종 × 2개 = 10개
주문: 10종 × 5개 = 50개
기대 시간: < 1초
```

#### TC-014: 중규모 (Medium)
```
재고: 10종 × 5개 = 50개
주문: 20종 × 5개 = 100개
기대 시간: < 10초
```

#### TC-015: 대규모 (Large)
```
재고: 20종 × 5개 = 100개
주문: 50종 × 10개 = 500개
기대 시간: < 60초
```

## 3. 알고리즘 비교 테스트

### 3.1 비교 메트릭
각 알고리즘에 대해 동일한 입력으로 다음을 측정:

| 메트릭 | 설명 | 중요도 |
|--------|------|--------|
| **총 비용** | α×자투리 + β×용접 | ⭐⭐⭐ |
| **실행 시간** | 밀리초 단위 | ⭐⭐⭐ |
| **사용 재고** | 사용한 재고 개수 | ⭐⭐ |
| **재료 효율** | 주문 총 길이 / 사용 재고 총 길이 | ⭐⭐ |
| **용접 횟수** | 발생한 용접 수 | ⭐ |

### 3.2 비교 결과 예상

| 알고리즘 | 총 비용 | 속도 | 최적성 | 용도 |
|---------|---------|------|--------|------|
| **Origin** | 중간 | ❌ 매우 느림 | ⚠️ 불확실 | 사용 불가 |
| **Current (DP)** | 나쁨 | ✅ 빠름 | ❌ 비용 무시 | 현재 사용 중 (문제) |
| **FFD** | 중간 | ✅ 매우 빠름 | ⚠️ 근사해 | 빠른 초안 |

## 4. 검증 체크리스트

### 4.1 정확성 검증
- [ ] 모든 주문 수량 충족
- [ ] 주문 길이 정확히 일치 (용접 포함)
- [ ] 재고 수량 초과 안함
- [ ] 음수 자투리 없음

### 4.2 제약 검증
- [ ] 용접 조각 길이 ≥ δ
- [ ] 재사용 자투리 ≥ γ
- [ ] 폐기 자투리 < γ

### 4.3 비용 검증
- [ ] 자투리 비용 = Σ(폐기 자투리) × α
- [ ] 용접 비용 = (용접 횟수) × β
- [ ] 총 비용 = 자투리 비용 + 용접 비용
