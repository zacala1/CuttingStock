# 철근 절단 최적화 문제 정의서

## 1. 문제 개요

### 1.1 도메인
**Cutting Stock Problem (절단 재고 최적화)** - 철근(Rebar) 절단에 특화

### 1.2 비즈니스 배경
건설 현장에서 다양한 길이의 철근 주문을 처리할 때, 표준 길이의 재고 철근을 절단하여 주문을 충족해야 합니다. 이 과정에서 발생하는 자투리와 용접 작업은 직접적인 비용으로 이어지므로, 최적화가 필수적입니다.

## 2. 입력 데이터

### 2.1 재고 (Stock)
- **길이 (Length)**: mm 단위, 양의 정수
- **수량 (Quantity)**: 사용 가능한 개수
- 예: `{ Length: 12000mm, Quantity: 10 }`

### 2.2 주문 (Order)
- **길이 (Length)**: mm 단위, 양의 정수
- **수량 (Quantity)**: 필요한 개수
- 예: `{ Length: 5000mm, Quantity: 5 }`

### 2.3 비용 파라미터
| 파라미터 | 설명 | 단위 | 일반적 값 |
|---------|------|------|-----------|
| **α (alpha)** | 자투리 1mm당 비용 | 원/mm | 1 |
| **β (beta)** | 용접 1회당 비용 | 원/회 | 500 |
| **γ (gamma)** | 재사용 가능한 자투리 최소 길이 | mm | 100-1000 |
| **δ (delta)** | 용접 가능한 조각 최소 길이 | mm | 100-1000 |

## 3. 제약 조건

### 3.1 물리적 제약
1. **재고 길이 제약**: 주문 길이 ≤ 재고 길이 (단, 용접 허용 시 예외)
2. **수량 제약**: 사용한 재고 수량 ≤ 보유 재고 수량
3. **절단 가능성**: 하나의 재고에서 여러 조각 절단 가능

### 3.2 용접 제약
1. **용접 가능 길이**: 용접 시 각 조각 ≥ δ (delta)
2. **용접 횟수**: 하나의 주문을 여러 조각에서 절단 시 용접 필요
3. 예: 5000mm 주문을 3000mm + 2000mm로 절단 → 용접 1회

### 3.3 자투리 처리
1. **재사용 가능 자투리**: 남은 길이 ≥ γ (gamma) → 재사용 목록에 추가
2. **폐기 자투리**: 남은 길이 < γ → 비용으로 계산

## 4. 목적 함수

### 4.1 총 비용 최소화
```
총 비용 = (폐기 자투리 총 길이 × α) + (용접 횟수 × β)
```

### 4.2 세부 계산
```
폐기 자투리 = Σ(재고별 남은 길이 < γ)
용접 횟수 = Σ(주문별 절단 횟수 - 1)
```

### 4.3 부차적 목표
1. 사용한 재고 개수 최소화
2. 재사용 가능한 자투리 최대화
3. 절단 횟수 최소화 (작업 시간 단축)

## 5. 출력 결과

### 5.1 절단 계획
각 재고에 대한 절단 리스트:
```
12000mm 재고 → [5000mm, 3000mm, 3000mm] (남은 자투리: 1000mm)
```

### 5.2 성능 지표
- **총 비용**: α × 폐기 자투리 + β × 용접 횟수
- **재고 사용 개수**: 사용된 재고의 총 개수
- **용접 횟수**: 발생한 용접 작업 수
- **자투리 현황**:
  - 재사용 가능 자투리 목록
  - 폐기 자투리 총 길이
- **재료 효율**: (주문 총 길이 / 사용 재고 총 길이) × 100%

## 6. 알고리즘 요구사항

### 6.1 기능적 요구사항
1. ✅ **정확성**: 모든 주문을 정확히 충족
2. ✅ **실행 가능성**: 물리적/용접 제약 준수
3. ⚠️ **최적성**: 총 비용 최소화 (최적해 or 근사해)

### 6.2 비기능적 요구사항
1. **성능**:
   - 소규모 (재고 <10, 주문 <20): 1초 이내
   - 중규모 (재고 <50, 주문 <100): 10초 이내
   - 대규모 (재고 <100, 주문 <500): 1분 이내

2. **확장성**:
   - 다양한 재고 길이 조합 지원
   - 비용 파라미터 실시간 조정 가능

3. **사용성**:
   - 명확한 결과 출력
   - 절단 계획 시각화
   - 비용 구성 상세 분석

## 7. 구현

현재 3종의 1D 솔버(`ICuttingSolver`)와 3종의 2D 솔버(`ICuttingSolver2D`)가 구현되어 있다.
상세는 `docs/ALGORITHMS.md` (1D) 및 `docs/2D_ALGORITHMS.md` (2D) 참조.

## 9. 참고 문헌

### 9.1 이론적 배경
- **Cutting Stock Problem**: NP-hard 조합 최적화 문제
- **Bin Packing Problem**: 쌍대 문제
- **Column Generation**: Dantzig-Wolfe 분해

### 9.2 표준 알고리즘
1. **FFD (First Fit Decreasing)**: 근사 비율 11/9
2. **BFD (Best Fit Decreasing)**: 평균적으로 FFD보다 우수
3. **Column Generation + Branch & Price**: 최적해
